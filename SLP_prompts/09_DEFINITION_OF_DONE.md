# Definition of Done

The project is SLP-ready only when every item below is true.

## Functional

- [ ] Microphone input works.
- [ ] Speech is converted to text.
- [ ] Recognized text is visible.
- [ ] Text reaches the deep-learning classifier.
- [ ] Model returns an intent.
- [ ] Confidence is available.
- [ ] Appropriate action executes.
- [ ] Chatbot response is visible.
- [ ] TTS works where supported.
- [ ] Unknown/low-confidence commands are handled safely.

## Machine Learning

- [ ] Dataset is version controlled.
- [ ] Dataset labels are documented.
- [ ] Train/validation/test split exists.
- [ ] No duplicate leakage exists.
- [ ] Neural model is actually trained.
- [ ] Model artifact is saved.
- [ ] Tokenizer is saved.
- [ ] Label mapping is saved.
- [ ] Evaluation script exists.
- [ ] Accuracy is measured.
- [ ] Precision is measured.
- [ ] Recall is measured.
- [ ] F1 is measured.
- [ ] Confusion matrix exists.
- [ ] Results are reproducible.

## Engineering

- [ ] Existing features remain functional.
- [ ] Frontend builds successfully.
- [ ] ML service starts successfully.
- [ ] API contract is documented.
- [ ] Error states are handled.
- [ ] No secrets are committed.
- [ ] No unnecessary generated directories are committed.
- [ ] README explains setup and architecture.

## UX

- [ ] UI is visually coherent.
- [ ] Voice state is obvious.
- [ ] Transcript is easy to read.
- [ ] Response is easy to read.
- [ ] Technical ML details are secondary.
- [ ] Mobile layout works.
- [ ] Keyboard/text fallback exists.
- [ ] Accessibility basics are covered.

## Deployment

- [ ] Frontend is publicly accessible.
- [ ] ML API is reachable in production.
- [ ] HTTPS is used.
- [ ] CORS is configured correctly.
- [ ] Model artifact is available.
- [ ] Public voice interaction works.
- [ ] A clean-browser test passes.

## Submission

- [ ] Live link
- [ ] Source code
- [ ] Brief report
- [ ] Dataset documentation
- [ ] Model architecture
- [ ] Methodology
- [ ] Results
- [ ] Screenshots
- [ ] Viva preparation
