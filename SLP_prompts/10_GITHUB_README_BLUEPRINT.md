# VOXEL
### Voice Intelligence Shopping Assistant

A voice-first shopping assistant that converts natural speech into structured shopping actions using speech recognition and a deep-learning intent classifier.

## Why this project?

The system combines:

```text
Speech Recognition
+
Deep Learning NLP
+
Entity Extraction
+
Shopping Actions
+
Voice Response
```

## System flow

```text
Voice
→ Speech-to-Text
→ Intent Classification
→ Entity Extraction
→ Action
→ Response
```

## Key features

- real-time voice input,
- transcript display,
- deep-learning intent classification,
- confidence-aware predictions,
- shopping-list operations,
- product search,
- recommendations,
- substitutes,
- optional text-to-speech,
- responsive interface.
